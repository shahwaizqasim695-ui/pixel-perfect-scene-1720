# Laura Jerlinski Author Website

## Experience
- Replace the home placeholder with a cinematic, editorial homepage for *Believing While Broken*.
- Crop the supplied wrap cover into an unchanged front-cover image and a small authentic author portrait; keep the manuscript private.
- Build the six requested pages: Home, About, The Book, My Journey, Recovery Resources, and Contact, with working navigation and responsive layouts.
- Use manuscript/cover facts only, short approved excerpts, verified US support links, and no invented reviews, credentials, availability, or contact details.
- Make contact and newsletter forms transparent about pending integrations; validate entries but never claim delivery or subscription without a live service.

## Visual direction
- Follow the supplied dark-to-golden cover art: restrained gold detailing, cinematic light, paper-like editorial textures, warm ivory moments, and premium serif typography.
- Use accessible menus, accordions, forms, subtle motion, reduced-motion support, and mobile-first spacing.

## Technical details
- Keep the existing TanStack Start framework and file-based navigation; React Router DOM is not compatible with this project's fixed stack.
- Define the visual system in `src/styles.css`, keep shared content in centralized data, and add route-specific metadata for each page.
- Add focused tests for route coverage and any user-facing rules that need protection; verify the preview at desktop and mobile sizes.
